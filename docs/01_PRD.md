# PRD — 현장별 공정·기성 대시보드

## 한눈에 보기

1. 본사 공무팀 담당자가 매달 현장 12곳의 공정·기성 자료를 한 화면에서 비교하는 PC 웹 앱입니다.
2. 첫 화면은 12개 현장 비교표이고, 큰 숫자와 점검 순위가 함께 보입니다.
3. 점검 현장 한 줄을 누르면 현장별 비교표에서 그 줄이 강조되고 기록이 펼쳐집니다.
4. CSV는 원본 열에 기성률·공정차이·상태·당월기성액 열이 추가된 형태로 내려받습니다.
5. AI는 현장끼리 비교하는 질문에 프로그램이 계산한 숫자와 기록된 내용을 근거로 답합니다.

이 문서의 자료는 교육용 가상 자료입니다. 실제 동일토건의 계약·현장·청구 자료가 아닙니다.

## 누가·언제·왜 쓰는지

| 항목 | 내용 | 근거 |
|---|---|---|
| 누가 | 본사 공무팀 담당자 | 질문 1 답 A. 매달 현장 자료를 모아 보고하는 일을 하는 사람입니다. |
| 언제 | 매달, 월말 자료가 모인 뒤 | 자료의 한 행이 "한 현장의 한 달 월말 상태"입니다. |
| 무엇을 보나 | 12개 현장(A~L)의 2025년 10월~2026년 9월 공정·기성 현황 | 144행·15개 열 자료입니다. |
| 왜 쓰나 | 늦어진 현장을 찾고, 그 현장에 기록된 상황과 대응 계획을 확인해 보고하려고 씁니다. | 점검 현장 찾기와 기록 확인이 한 화면 안에서 이어집니다. |

## 줄이고 싶은 불편

| 우선순위 | 불편 | 근거 |
|---|---|---|
| 가장 먼저 | 현장별 엑셀을 하나씩 열어 비교하는 시간 | 질문 2 답 A |

- 자료를 가져오면 12개 현장이 한 표에 모이므로 현장별 파일을 열어 비교하지 않아도 됩니다.
- 이 자료에서 확인된 어려움: 9월 전체 공정차이는 −2.0pp로 주의 수준이지만 D 현장은 −10.7pp입니다. 전체 숫자만 보면 D가 가려지므로 현장별 숫자를 한 표에서 봐야 합니다.

## 만들 기능

필수 기능 5개입니다. 모두 `실습조건.md`의 범위이며 빼거나 미루지 않습니다.

| 번호 | 기능 | 하는 일 | 근거 |
|---|---|---|---|
| 1 | 자료 가져오기 | CSV 또는 JSON 파일을 검사하고 미리 보여 준 뒤 전체를 바꿉니다. 오류가 있거나 취소하면 지금 자료를 그대로 둡니다. 같은 자료를 CSV와 JSON으로 차례로 가져와도 144행입니다. | 잘못된 파일 때문에 보고 있던 자료가 바뀌는 일을 막습니다. |
| 2 | 현황 보기 | 처음에는 2026년 9월·전체 현장을 보여 줍니다. 월·지역·공사 유형·현장을 고를 수 있습니다. 전체 기성률, 계획·실제 공정률, 공정차이를 큰 숫자로 보여 줍니다. 선택 월까지의 계획·실제 공정률 추이와 월별 기성 막대도 보여 줍니다. | 가장 최근 월에서 시작해 매달 같은 순서로 확인할 수 있습니다. |
| 3 | 점검 현장 찾기 | 공정차이(실제 − 계획)로 정상·주의·점검을 나눕니다. 점검 현장은 공정차이가 작은 순, 같으면 현장 ID 순으로 보여 줍니다. 비교표의 행을 펼치면 공사기간·기록된 상황·대응 계획이 나옵니다. | 판정 기준은 `데이터설명.md`의 교육용 규칙입니다. |
| 4 | CSV 내보내기 | 지금 고른 월·지역·유형·현장과 같은 범위를 내보냅니다. 원본 열에 기성률·공정차이·상태·당월기성액 열을 추가하고, 엑셀에서 한글이 깨지지 않게 합니다. | 질문 6 답 B. 엑셀에서 다시 계산하지 않아도 되게 하려는 것입니다. |
| 5 | AI에게 묻기(Gemini API) | 계산은 프로그램이 하고, AI는 그 숫자와 기록된 내용을 근거로 설명합니다. 자료에 없는 내용(실제 준공일·미수금 등)은 알 수 없다고 안내합니다. 월·지역·유형·현장을 바꾸면 이전 답변을 지웁니다. AI 연결이 실패해도 대시보드와 CSV는 계속 씁니다. | AI가 숫자를 직접 계산하면 틀릴 수 있어서 계산과 설명의 역할을 나눕니다. |

### 이번 PRD에서 정한 내용

| 항목 | 정한 것 | 근거 |
|---|---|---|
| 첫 화면에서 가장 먼저 보여 줄 것 | 12개 현장 비교표 | 질문 3 답 C |
| 점검 현장 한 줄의 숫자 | 계획 공정률·실제 공정률·기성률 모두 | 질문 4 답 C. 공정이 늦은 것인지 기성이 늦은 것인지 구별됩니다. 예: D는 계획 86.5%·실제 75.8%·기성률 69.4%입니다. |
| 점검 현장 한 줄을 누르면 | 현장별 비교표로 가서 그 줄을 강조하고 기록을 펼침 | 질문 5 답 A |
| 내려받은 CSV의 용도 | 엑셀에서 더 계산하기 | 질문 6 답 B |
| AI에게 주로 묻는 것 | 현장끼리 비교 | 질문 7 답 C |

### AI에게 묻기 — 현장 비교 질문의 기준 (AI 결정)

| 항목 | 정한 것 | 근거 |
|---|---|---|
| 예시 질문 | ① 점검 현장 D, I, K 중 공정차이가 가장 큰 곳은?<br>② 경기 현장끼리 기성률을 비교해 줘.<br>③ D와 I의 기록된 대응 계획은 어떻게 다른가? | 질문 7 답 C를 반영합니다. |
| 비교 범위 | 지금 고른 범위 안의 현장끼리만 비교합니다. | AI는 지금 필터 범위의 자료만 받습니다. |
| 현장 1곳만 고른 경우 | "비교하려면 현장을 2곳 이상 포함하는 범위를 고르세요"라고 안내합니다. | 비교할 대상이 범위에 없기 때문입니다. |
| 답변 방식 | 숫자와 기록된 내용을 나란히 설명합니다. 어느 현장이 더 잘했다는 평가나 원인 확정은 하지 않습니다. | 기록된 상황·대응 계획은 완료 사실이나 원인 확정이 아닙니다. |
| 답변에 표시할 것 | 기준 월, 현장 ID, 근거 숫자, 참고한 기록 필드 | 답변을 자료와 대조해 볼 수 있어야 합니다. |

## 만들지 않는 것

| 만들지 않는 것 | 이유 |
|---|---|
| 로그인 | 한 사람이 자기 PC에서 쓰는 교육용 앱입니다. |
| 데이터베이스 | 파일을 브라우저에서 읽고 계산합니다. |
| 회사 시스템 연동 | 교육용 가상 자료만 씁니다. |
| 실제 기성 청구·발주 | 이 앱은 현황을 보는 용도입니다. |
| 일정 예측 | 계약상 준공일은 예정 일정이며 실제 완료일 예측이 아닙니다. |
| 새로고침 후 자료 유지 | 새로고침하면 파일을 다시 가져옵니다. |
| 별도 상세 페이지 | 현장 기록은 비교표 안의 펼침 행에서 봅니다. |
| GitHub 저장·Vercel 배포의 자동 실행 | 사용자가 별도로 요청한 뒤에만 진행합니다. |

## 성공 기준

`실습조건.md`의 "정답 숫자" 표와 같은 결과가 나오는 것입니다. 별도의 성공 기준을 새로 정하지 않았습니다.

| 확인할 것 | 정답 |
|---|---|
| 9월 전체 | 계약금액 630,700 · 누적기성액 424,063.4(백만원) · 기성률 67.2% |
| 9월 공정률 | 계획 73.2% · 실제 71.2% · 공정차이 −2.0pp |
| 9월 당월기성액 | 28,878.7백만원 |
| 9월 점검 순서 | D(−10.7pp) → I(−7.6pp) → K(−5.4pp) |
| 9월 상태 내역 | 정상 6곳 · 주의 3곳 · 점검 3곳 |
| 2025-10 | 당월기성액 계산 불가, 누적액으로 대신하지 않음 |
| 오류 파일 3종 | 모두 거부, 지금 자료 유지 |

나머지 정답은 `실습조건.md`의 표와 `data/검산표.md`를 따릅니다.

## 화면 요약

1. 페이지 4개: 현황 요약(첫 화면), 현장별 비교표, 자료 가져오기, AI에게 묻기.
2. 상태 5개: 자료 없음, 가져오기 오류, 점검 대상 없음, AI 답변 기다리는 중, AI 연결 실패.
3. 첫 화면 순서(AI 결정): 월·지역·유형·현장 선택 → 큰 숫자 4개 → 12개 현장 요약표(현장·계획·실제·공정차이·기성률·상태) → 점검 순위 → 계획·실제 추이와 월별 기성 막대.
4. 점검 순위 한 줄: 현장명·계획 공정률·실제 공정률·공정차이·기성률. 누르면 현장별 비교표로 이동해 그 줄을 강조하고 기록을 펼침.
5. 현장별 비교표: 12개 현장의 지역·유형·주요 공종·금액·공정·상태. 펼침 행에 공사기간·기록된 상황·대응 계획.
6. 숫자 단위: 금액은 백만원, 기성률·공정률은 %, 공정차이는 pp이며 모두 소수 첫째 자리.
7. 상태 구분: 정상(0pp 이상), 주의(−5pp 초과 0pp 미만), 점검(−5pp 이하)을 글자와 색으로 함께 표시.
8. AI에게 묻기: 지금 범위 표시, 현장 비교 예시 질문 3개, 답변과 기준 월·현장·근거 숫자·기록 필드.
9. 예시 숫자: 9월 전체 기성률 67.2%·공정차이 −2.0pp·정상 6/주의 3/점검 3, D는 계획 86.5%·실제 75.8%·−10.7pp·기성률 69.4%.
